# Source Code

This directory contains the embedded software developed for the Intelligent Wireless Power Transfer for EVs project.

## Modules

- Arduino UNO – Main controller and sensor data processing.
- IR Proximity Sensor – Misalignment detection.
- ACS712 – Current measurement.
- Voltage Sensor – Voltage measurement.
- ESP8266 – Wi-Fi connectivity and IoT data transmission.
- OLED Display – Charging parameter display.
- Buzzer – Misalignment alert.

## Programming Language

Embedded C/C++ using Arduino IDE.

## Security Note

Wi-Fi credentials and ThingSpeak API keys must be configured locally and must not be committed to this public repository.
